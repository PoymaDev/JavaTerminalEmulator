# Эмулятор командной строки на Java (JavaTerminalEmulator)

Проект представляет собой простой кроссплатформенный эмулятор командной строки
с графическим интерфейсом, разработанный на языке Java с использованием
библиотеки Swing. Программа имитирует работу консоли операционной системы
внутри изолированной среды виртуальной файловой системы, которая строится на
основе реальной физической папки компьютера. Проект наглядно демонстрирует
принципы парсинга строк, управления структурой папок в памяти и работы с
графическими окнами Java.

# Программа поддерживает четыре встроенные команды:

• ls — сканирует список файлов и выводит содержимое текущей директории или пути
из аргумента.

• cd — осуществляет проверку путей и изменяет текущую рабочую виртуальную папку
эмулятора.

• conf-dump — выводит в окно текущие значения путей к виртуальному диску и файлу
стартового скрипта

• exit — выводит уведомление на экран и полностью завершает работу виртуальной
машины Java.

# Обработка данных выполняется четырьмя методами:

• cdParser — разбирает входящую строку на отдельные слова-токены с помощью
регулярных выражений.

• executeCommand — извлекает первое слово как команду и запускает её выполнение
через оператор switch.

• executeStartScript — считывает внешний текстовый файл и последовательно выполняет написанные там команды.

• scanDirectory — рекурсивно обходит реальную папку на диске и строит карту файлов
для виртуальной системы.
